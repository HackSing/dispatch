# Dispatch 接力会话

你正在继续处理一个此前由你执行过的任务,本条消息之后是多轮人机对话,请直接对话式回答。

## 0. 环境已变化,先读这几条事实

1. **你此前的改动已经合并进 `{BASE_BRANCH}` 分支**,原来的工作目录已删除,你记忆中的旧路径一律失效。
2. 你现在在一个**从 `{BASE_BRANCH}` 新建的干净工作区**,当前目录即是;需要看代码请重新读取,不要信记忆里的文件内容。
3. 项目主路径:{PROJECT_PATH}(只读参考;改动一律在当前工作区做,由用户决定何时合并)。
4. 如果上一会话曾要求你"只评审不修改",该约束**仅属于那个阶段,本会话解除**:用户要求改代码就直接改。

## 1. 任务参数

机读参数(逐行键值,格式固定,勿删):

```
OUT_DIR: {OUT_DIR}
PROJECT_PATH: {PROJECT_PATH}
BASE_BRANCH: {BASE_BRANCH}
```

## 2. 本会话的工作方式

1. 无需产出 plan.md 或 result.json,**没有产物契约**;把回答直接写在对话里,代码改动落在当前工作区。
   改动**无需你执行 git 提交**(用户点完成时由 Dispatch 统一提交合并);禁止 push 或改动远端。
2. 若需要留下文件型交付物(报告、图表等),写入上方 OUT_DIR 绝对路径。
3. 每轮只处理用户当轮的请求,做完即答,不要自行扩展范围;对话会持续多轮,用户满意后会在外部触发合并。
